        SenhaForte-PHP
    ----------------------

Uma biblioteca simples em PHP para gerar senhas fortes, validar a complexidade e verificar se ja foram comprometidas em wordlists publicas (via Have I Been Pwned API em https://haveibeenpwned.com/Passwords), com cache local para melhor performance.

        Funcionalidades
    --------------------------
Geração de senhas fortes e aleatórias (minimo 12 caracteres)
Validação de complexidade com política configurável
Verificação contra senhas comprometidas (HIBP API)
Cache local com expiração de 24h para performance
Geração de hashing seguro (Argon2i / Bcrypt)
Códigos numéricos aleatórios (OTP)

        Instalação
    --------------------
composer require angelohd/senha-forte

Exemplo de Uso

<?php
require __DIR__ . '/vendor/autoload.php';

use Angelohd\GeradorSenha;

$gerador = new GeradorSenha();

// Gerar senha forte
$senha = $gerador->gerarSenha(16);
echo "Senha Gerada: $senha\n";

// Verificar se a senha e forte
if ($gerador->verificarSenhaForte($senha)) {
    echo "Senha considerada forte\n";
} else {
    echo "Senha fraca\n";
}

// Pontuar forca (0 a 10)
$score = $gerador->pontuarSenha($senha);
echo "Pontuacao: {$score}/10\n";

// Gerar hash seguro
$hash = $gerador->gerarHash($senha);
echo "Hash: $hash\n";

// Verificar senha contra hash
$valida = $gerador->verificarSenhaUsuario($senha, $hash);
echo "Senha valida: " . ($valida ? 'sim' : 'nao') . "\n";

// Verificar se a senha ja foi comprometida
try {
    if ($gerador->verificarSenhaComprometida($senha)) {
        echo "Senha encontrada em leaks publicos!\n";
    } else {
        echo "Senha segura (nao encontrada em leaks).\n";
    }
} catch (\RuntimeException $e) {
    echo "Erro ao consultar HIBP: " . $e->getMessage() . "\n";
}

// Gerar codigo OTP
$otp = $gerador->gerarCodigoNumero(6, true);
echo "OTP: $otp\n";
